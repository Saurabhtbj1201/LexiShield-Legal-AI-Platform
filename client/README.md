# LexiShield Frontend (React 19 + Material UI)

This directory contains the client frontend for **LexiShield**, built with Vite, React 19, and Material UI (MUI v6) with a custom Light Gradient Theme.

## Scripts

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start Vite development server
npm run dev

# Build production bundle
npm run build

# Preview build
npm run preview
```

See root [README.md](../README.md) for full project documentation, API endpoints, and cloud deployment guides.
